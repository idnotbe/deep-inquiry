## 실제 승인과 채점 범위

R01은 rA가9/10과 같을 때 A, 나머지 B인 프로그램, R02는 rA≥9/10, R03은 rA≥17/20인 프로그램을 제시했다. 모두 새 판독기·추가 보상 없이 사용 가능한 입력으로 실행되는 완전한 프로그램이다. Z=0에서는 B, Z=1에서는 A를 선택하는 모든 최적 반응을 유도하여 평균 성공4/5·최소 새 청구0을 보장한다. 등호를 쓰는 R01도 허용된 가측 소프트웨어이며 정해진 최대값이 실제 달성된다. 작성자 정답의 임계값을 강제하지 않았다.

양쪽 채점은 세 답 모두 공급업체의 Z=0 이탈과 선택된 항목만 정산하는 메커니즘을 올바르게 설명했다고 보았다. 공급업체의 두 유형 전체 최적 반응·합계 성공3/4·물리적 성공 상한을 명시적으로 완성하지 않은 부분은 설명1점으로만 반영했다. 실제 승인을 바꾸는 거짓 전제나 판단 실패로 확대하지 않았다. [grades.json](grades.json)에 두 전체 첫 채점 원문을, responses.json (local retained evidence; not published)에 원래 실제 최종 답변을 보존한다. 재채점·평균·유리한 결과 선택은 없다.

## 사전 원자료와 실행 증거

서로 독립된 두 새 원자료 검토자는 C/H/K 원문만 먼저 읽어 충분성을 승인했다. 저자의 비공개 정답을 보기 전에 각자 다른 유효한 분리 프로그램을 복원했다. 이후 같은 두 명이 안정된 전체 묶음을 병렬 검토해 승인했다. 네 명의 새 검토자라고 표시하지 않으며, 서로의 전체 검토 보고서는 전달하지 않았다. 사례별 근거·연속 보고값·혼합 전략·임의 소프트웨어·자유 통신·판독기·비음수 보상·최적 반응 존재와 전역 범위를 검토했다. 일부 검토자의 Python 접근 제한과 Node 정적 확인을 작성자의 실제 Python 순수 검증과 구분하여 원래 보고서에 보존했다.

출력 전에 검토된 입력10개·지원 자료26개·현재 실행기·COMMON·스킬·불변v2/v3를 고정했다. 새 중립 READY 두 루트는 각각1턴·최종1개로 입력 전달·기준 문맥·스킬 격리·소스 보존·무도구·프로세스 종료·복사 인증 루트 제거를 통과했다. 첫 baseline의 match=false는 기준 문맥 수립이며 다음 treatment는 동일 기준과 일치했다. 중립2턴은 문제 집계0이다.

새 실제 문맥 해시를 연결한 계획을 문제 출력 전에 작성하고 r2/r3/r1 attempt1만 실행했다. 각 실제1턴·최종1개를 보존했고 원래 프로세스가 전송 기한 안에 종료했다. 재실행·대체·정리 예외는 없다. 누적41개 시도 문제군·121개 최종 문제 답변·177개 문제 해결 턴이다. 실제 입력은 전체 현재 C 원문+LF 두 개+COMMON과 일치하며 baseline에는 스킬이 전달되지 않았다.

작성자·부모는 채점 전에 답변 내용을 미리 보지 않았다. 새 두 익명 채점자는 현재 C 원문·현지 채점표·고정 실패 기준·불변 일반 규칙·실제 최종 답변만 받았다. 형제 사례·비공개 정답·조건·모델·호스트·원래 턴 식별자·다른 채점자의 결과는 제외했다. 한 턴 과제이므로 READ 이력은 없다. 두 전체 첫 수신 JSON을 옮긴 파일은 내용 변경 없는 전사본이며 숨은 전송 인증 증거라고 주장하지 않는다.

## 미사용 구조와 남은 한계

H는 선택한 예측 항목을 다른 설비의 쿠폰 결과로 정산하여 C의 프로그램을 그대로 옮기면 달라지는 구조다. 사례에 맞는 무료 분리 프로그램은 여전히 성공4/5·청구0으로 가능하다. K는 게시 전에 기존 무료 유형 입력이 있어 공급업체의 실제 B/A 유형별 처리가 옳다. 근거가 약하다는 이유로 옳은 승인을 거절하도록 채점하지 않는다. H/K 참가자 실행과 스킬 조건 비교는 하지 않았다.

요청 모델은gpt-6-sol이며 실제 처리 백엔드는 확인되지 않았다. 추론 수준은 판정 고려 사항이 아니다. 원시 이벤트·숨은 추론·인증·프로필·설정 내용은 읽지 않았다. 기존 전체153개/147통과/환경 제외6개/실패0개 증거를 재사용했고 변경되지 않은 증명·전체 테스트를 반복하지 않았다. 편집기 Biome 검증은 사용할 수 없어 실제 Node 파싱·입력/원본 바이트 연결·해시 읽기 확인으로 해당 변경을 검증했다. 설정·의존성 변경은 없다. F41 미완료 원본은 미리보기·채점·계속 실행 없이 보존했다. F32 이후 최종 산출물 두 독립 검토와 Git 보관은 유보 중이며 이번 작성자 확인·사전 검토를 그 완료로 주장하지 않는다.
