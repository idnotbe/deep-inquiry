# F136 로컬 결과

F136은 EXCLUDED_NOT_HARD로 제외했다. 두 독립 블라인드 FIRST 채점자가 원본 답변 세 개에 각각 10/10/10을 부여했다. 객관적 오류는 각각 0/3, 채택 요건에 해당하는 탐구 실패도 각각 0/3이다. 함께 지목한 실패는 0건이며 채택 기준인 동일 원본 2/3에 미달한다. 유지된 어려운 문제군은 0/6이다.

세 답변 모두 매 교대 전에 Alder를 작업하는 실행 가능한 목록을 제시했다. 교대별 절감량은 8, 5, 2시간이며, 효과가 교대 종료 때 사라지므로 매번 Alder를 선택하면 총 손실 90시간을 달성한다. 기존 배정은 Alder와 Birch를 번갈아 골라 99시간을 잃는다. 짧은 정답으로도 이 차이를 충분히 설명했으므로 이번 후보는 요구된 난이도를 충족하지 못한다. 모든 문제나 모델 전반에 대한 난이도 결론은 아니다.

원본 실행 순서는 2, 3, 1이고 익명 대응은 R-A=r1, R-B=r3, R-C=r2이다. 원본 완료 3회와 전체 최종 답변 3개, 채점하지 않은 중립 실행 2회가 보존되었다. 재시도와 참여자 재실행은 0회다. 요청 모델은 gpt-6.1-sol, 요청 노력 수준은 medium이며 적용된 호스트 설정은 확인했다. 실제 백엔드는 UNKNOWN이고 노력 수준은 실패 판정 근거가 아니다. 저장된 스레드의 고유성은 별도로 입증하지 않았다.

원문은 C/H 두 문제이며 스키마 항목 세 개 중 하나는 포장용 별칭이다. H와 별칭은 참여자에게 사용하지 않았고 검증된 음성 대조군으로 세지 않는다. 점수 비교용 처치 조건 실행은 0회이며, 중립 실행 두 회 중 처치 한 회는 실행환경 확인용이다. 스킬 효과와 H의 실증 난이도는 UNKNOWN이다. 여섯 문제군 완성이나 효과 입증을 주장하지 않는다.
