# 두 번째 후보 묶음: 7개 문제군 모두 난도 미달

실제 스킬 없는 응답21개가 모두 완전 통과했다. 독립 채점자A·B는 동일하게208/210점, 완전 통과21/21로 판정했다. 사전 기준은 문제군별3회 중 완전 통과2회 이상 또는 평균7점을 넘으면 제외한다. 따라서 이번7개 문제군은 모두 제외하며, 확보한 어려운 문제군은0개다. 스킬 효과를 비교한 결과가 아니다.

F04의2개 응답은 실행 가능한 정답과 비용을 모두 제시했지만 더 싼 보장 정책이 없는 이유를 충분히 설명하지 않아1점씩 감점됐다. 두 채점자는 이를 핵심 작동 방식의 실패로 보지 않았다. 다른 응답에서도 중요한 전제·증거·참여자 반응·실행 가능성을 놓친 실패가 확인되지 않았다. 짧은 정답을 길이 때문에 감점하지 않았다.

작성 후 독립1차 검토를 거쳐 모순된 수요 문장을 수정하고, 순수 산술·표현 오류로 낮은 점수를 받은 사례를 채택하지 않는 조건과 채점자 판단 충돌 처리법을 프로토콜에 고정했다. 확인용 사례는 처음의 쉬운 조건 반전 초안을 교체해 같은 판단 난점을 유지했다. 독립2차 검토가 최종 문항·해법·채점표를 확인한 뒤 바이트 해시를 동결했다. 모델 응답을 본 뒤 문항이나 채점 기준을 바꾼 적은 없다.

동결본의 중립 전달 확인2개와 실제 선별21개를 네이티브 호스트로 실행했다. 외부 Git Bash 호출은300초 응답 제한에 걸렸으나 원래 실행은 계속됐으며, 재실행 없이21개 모두 완료됐다. 모든 최종 응답 해시, 호스트 종료, 인증 사본 제거, 원본 보존을 확인했다. 원시 호스트 문맥·인증·비공개 로그는 공개하지 않는다. 요청한 모델은gpt-6-sol이며 실제 처리 백엔드는 확인되지 않았다. 추론 수준은 난도 선택이나 중단 조건으로 사용하지 않았다.

응답 원문 (local retained evidence; not published), [분리 보존한 독립 채점](grades.json), [안전하게 추린 실행 증거](evidence.json)를 보존했다. F02H–F08H와 대조 F02K는 사용하지 않았다. 확인 문항은 작성자가 본 자료이며 작성자에게 숨긴 문항이라고 주장하지 않는다. 점수화된 스킬 처치 실행과 스킬 수정은 없다.

문제는 공개 자료의 구조와 자체 추론에서 착안해 새로 작성했다. F02는 [개별 배정과 전체 시장 효과의 차이](https://arxiv.org/abs/2104.12222), F07은 [선택 정책과 관측 자료의 관계](https://www.nber.org/papers/w23180)를 참고했다. 공개 문항의 문장이나 정답을 옮기지 않았으며, 원 논문의 성적을 이번 모델의 난도로 전용하지 않는다. 나머지 작동 방식은 기존 설계 문서와 새로 만든 폐쇄형 운영 사례에서 구성했다.
