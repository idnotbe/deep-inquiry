# F157 — INCOMPLETE_PROTOCOL

F157 / source-pair-1은 동결 캡처 계약 불일치로 `INCOMPLETE_PROTOCOL`이다. 채점 `NOT_RUN`, 난도 `UNKNOWN`, 유지 **0/6**이다. 종료 문서의 독립 최종 검토와 ROOT 승인은 대기 중이다.

계획과 실제 모두 단일 턴 원본 3개이며, 각 원본의 최종 답변 1개씩 총 3개를 캡처 보존본 (local retained evidence; not published)의 `participants[*].unacceptedFinals.finals`에 보존했다. 원본 답변은 `UNACCEPTED_NOT_GRADEABLE`이며 정확한 문자열의 UTF-8 바이트 수·SHA-256을 [검증](verification.json)에 연결했다. 익명 채점 패킷, 채점자 호출, 점수 및 오류·inquiry failure 판정은 없다. 재시도·대체·후속 턴·추가 문제 턴·H 실행·중립 검사·스킬 비교·채점 처치는 모두 0회다. H는 작성자와 소스 검토자가 보았지만 참가자에게 사용하지 않았다.

독립 런타임 감사 (local retained evidence; not published)는 세 원본의 전체 입력 5,847바이트, 정확한 읽기 인수, 유일한 도구 호출과 반환값, 각 최종 답변·미러·완료 기록의 일치를 확인했다. 동결 파서는 148행의 최상위 키 검사 `set(event) == {'timestamp', 'type', 'payload'}`에서 첫 기록의 추가 `ordinal` 필드를 거부한다. 감사에 따르면 각 원본의 22개 기록 모두에 이 필드가 있고 4개에는 `metadata`도 있다. 입력·문맥 검사 전에 발생한 스키마 거부이며 **입력 전달 실패나 오답의 증거가 아니다**. 독립 감사는 이 사실을 설명하지만 동결 계약을 구제하거나 유효성을 승격하지 않는다. 파서 수정, 필드 제거, 재실행 없이 v2/v3의 무효 원본 불완전 처리 규칙을 유지한다.

실행 요청은 fresh native subagent, `gpt-6.1-sol` / `medium` / `fork_turns:none`이었다. 감사에서 관측한 구성값은 요청과 일치한다. 호출 기록 (local retained evidence; not published)은 부모가 제출한 인수의 기록이며, 보호된 초기 전달 봉투의 평문을 직접 확인한 증거는 아니다. 실제 숨은 백엔드와 완전한 격리는 미확인이고 파일시스템은 공유된다.

관측 가능한 문맥에는 일반 Codex 지침, 작업자 역할, 팀 운영, AGENTS, 환경·권한, 스킬 목록, 메모리 안내·요약이 있었다. 일반 메모리에는 과거 평가 작업과 무관한 Router 결과가 포함되지만, 이를 F157 답안·평가표 노출과 동일시하지 않는다. 감사는 관측 문맥에서 F157 원본 후보, H, oracle, 평가 지침·채점표, 이전 F157 답변, 부모의 진행 대화를 식별하지 못했다. 스킬 목록의 존재도 실제 스킬 본문 읽기나 처리 실행을 뜻하지 않는다. 보호된 초기 봉투와 백엔드 내부 내용까지 배제했다거나 문맥이 완전히 비어 있었다고 주장하지 않는다.

소스 독립 검토 A/B는 source-pair-1을 승인했다. 캡처 초기 검토 A는 수정 필요였고 v2 검토 B는 승인했으며 합성 검사 11/11과 별도 검사 11/11 통과를 보고했다. 이는 실제 호스트 스키마 수용의 증거가 아니다. 동결 pretrial·소스 freeze·protocol 및 캡처 checks의 과거 대기 문구와 오래된 pretrial 참조는 수정하지 않는다. 현재 v2 어댑터와 실제 pretrial 해시를 명시한 검토 B 및 런타임 감사를 별도로 연결한다.

[Manifest](manifest.json)는 소스·방법론·pretrial·캡처·검토·호출 기록·보존본의 현재 바이트 수와 SHA-256을 연결한다. 이 작성자는 참가자 세션을 다시 읽거나 답안을 채점하지 않았다. 새 종료 문서에는 원본 세션 식별자·경로·이벤트·비공개 추론을 옮기지 않았다. 카탈로그는 부모가 기존 바이트 접두부를 보존해 별도 추가하며 루트 README는 유지한다. 과거 사례의 재분류, 실증 난도·가족 독립성·스킬 효과 주장은 없다.
