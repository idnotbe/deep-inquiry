# F41 실제 난도 선별 상태 — 실행 보존 실패로 미완료

**첫 원래 슬롯 r2는 실제 한 차례에서 최종 응답을 완료했지만, 보호 대상 설정 파일의 실행 전후 보존 확인이 실패했다. 실행기가 종료되어 r3·r1은 시작하지 않았다. F41은 INCOMPLETE이며 난도가 낮거나 높다는 판정을 내리지 않는다. 원래 응답은 미채점·미대체로 보존했고, 확보0/6개로 여섯 문제군 모두 남는다.**

이는 응답 내용에 따른 제외나 낮은 점수 판정이 아니다. 응답 내용은 미리 보지 않았고 새 익명 채점 묶음·채점자·재채점도 만들지 않았다. 미사용 H·K와 점수화한 스킬 적용 조건은 실행하지 않았다. 최종 산출물 독립 검토와 보관은 기존대로 유보 상태다.

## 문제와 실행 전 검토

한 실패 장치에 설치된 원인은 A 또는 B 중 하나이며 진단·구매·납품 전체에서 고정된다. 원인에 대한 사전 확률은 없다. 유료 진단은 두 원인 모두에서 양·음 결과의 가능성이 있는 하나의 고정 부팅 기록이다. 부품은 실제 서비스를 복구하며, 주문 마감·설치 지연·무료 현재 서비스 읽기의 시점에 따라 진단과 복구를 결합하는 정책의 범위가 달라진다. 계약은 각 가능한 고정 원인에서 정책 전체의 기대 서비스3/4 이상을 보장하며, 원인별 전체 기대 청구 중 최대값을 최소화한다.

새 원자료 검토자 두 명은 C·H·K 원문만으로 각각41/32·33/32·3/4와 합법적인 전체 정책 범위를 복원하고 원자료 충분성을 APPROVE했다. 공급업체 제안의 REVISE와 원자료 승인 자체는 구분했다. K의 실제 무료 현재 원인 장치는 최적 승인을 지지하므로 일반 보정 근거의 부족만으로 그 승인을 거절하도록 요구하지 않았다.

서로 다른 새 전체 검토 A·B는 정확한10개 입력과14개 보조 파일, 정규화 입력과 현재 문항의 사실만 요구하는15개 채점 항목을 수정 요구 없이 승인했다. A는 별도 물리 서비스 모형에서 정수 배율로 C20·H30행을 검산했다. B는 별도 BigInt 유리수로 같은 행과 BOTH를 포함한 H42행을 확인했다. 모든 합법적 시점·기록·상관된 독립 외생 난수를 포함하는 범위는 별도 해석적 정규화 증명이며, 임의 프로그램 전체를 실행 열거했다고 보고하지 않는다. 기존 작성자 계산과 전체 테스트는 반복하지 않았다.

H는 부품 설치 뒤 현재 서비스를 읽고 마감 전에 보완 부품을 주문할 수 있는 미사용 구조다. K는 현재 A를 인증하는 무료 장치가 있는 미사용 대조다. 확인 문항은 작성자·검토자가 보았지만 참가자 실행에는 쓰지 않았다. 이 사전 타당성 승인은 실제 난도나 최종 산출물 독립 승인이 아니다.

## 실제 실행과 보존 실패

검토된 입력·방법론·현재 실행기·스킬·공통 길이 지시를 실제 출력 전에 동결했다. 기존 실행 파일의 메타데이터와 해시, 인증 파일의 존재만 확인했으며 인증 내용은 읽지 않았다. 새 중립 실행 두 번은 READY를 반환하고 실제 입력·공통 문맥·소스 보존·프로세스 종료·임시 인증 복사 정리를 통과했다. 첫 중립의 공통 일치 false는 새 기준을 만드는 단계이고 두 번째가 그 동일성을 확인했다. 중립2회는 문제 풀이 집계에 포함하지 않았다.

새 공통 문맥 해시를 고정한 실행 계획의 순서는 r2→r3→r1이다. r2 attempt1은 실제 응답을 완료하고 원문1877바이트를 저장했다. 도구 미사용, 현재 과제 뒤 공통 지시를 붙인 정확한 입력, 실제 공통 문맥, 프로세스 종료와 임시 인증 복사 정리는 통과했다. 그러나 실행 전후 보호 파일 영수증에서 `local-codex-home/config.toml`의 보존 상태가 false이며 파일은 이후에도 존재한다. 설정 내용·변경 주체·변경 이유는 확인하지 않았다. 해당 파일 내용이나 자격 증명 해시를 읽거나 보고서에 노출하지 않았다.

| 원래 슬롯 | 실제 문제 차례/최종 출력 | 상태 | 채점 |
|---|---:|---|---|
| r2, attempt1 | 1/1 | 완료 출력 보존, 소스 보존 실패로 무효 | NOT_RUN |
| r3 | 0/0 | 실행되지 않음 | NOT_RUN |
| r1 | 0/0 | 실행되지 않음 | NOT_RUN |

실행기는 실제 종료 코드1로 멈췄으며 도구 전송 대기 만료가 아니다. 이후 두 원래 슬롯을 계속하거나 첫 슬롯을 교체·재실행하지 않았다. 실제 완료와 유효성을 구분한다. 무효 응답이나 실행되지 않은 응답을 점수0·적격 실패·난도 근거로 바꾸지 않는다. 세 유효한 원래 슬롯을 요구하는 변경 없는 v2/v3에 따라 공동 실패 ID 판정도 수행하지 않았다.

동결한 문항·방법론·실행기·스킬 파일은 실패 뒤에도 해시 일치가 확인됐다. 보호 파일 전체 목록에서 변경된 것으로 관측된 항목은 위 설정 파일뿐이다. 원래 실행 영수증의 보존 실패를 해당 문항이나 스킬의 판단 실패로 확대하지 않는다.

## 원본·집계·남은 범위

원래 응답은 responses.json (local retained evidence; not published)에 그대로 보존했다. [grades.json](grades.json)의 채점·결정 오류·적격 실패 값은 모두 미실행이며0점으로 대체하지 않았다. [evidence.json](evidence.json)에 실제 슬롯·안전한 완료 통계·해시·입력 확인·보호 파일의 경로와 보존 여부·모델을 호출하지 않는 상태 확인 명령을 보존했다. 비공개 실제 영수증은 `temp/hard-screen-20261003/worker/F41/original/F41C-baseline-r2-attempt1/manifest.json`이고, 설정 변경의 경로 전용 메타데이터는 같은 디렉터리의 `source-receipts-private.json`에서 추출했다.

안전한 telemetry에서 완료된 문제 차례1개와 최종 메시지1개를 각각 확인했다. 직전36개 시도 문제군·108개 실제 출력·149개 문제 차례에 이번1개 시도 문제군·1개 출력·1개 차례를 더해 **37개 시도 문제군·109개 실제 최종 출력·150개 문제 차례**다. 남은 두 NOT_RUN 슬롯과 중립2회는 출력·문제 차례를 더하지 않는다. 이 누적에는 무효 원본도 포함되며 유효한 선별 완료 수나 성공률이라는 뜻이 아니다. 기존 형식 무효1개·모호성3개와 새 소스 보존 무효1개를 구분한다.

보고서 구조를 확인하면서 작성자 문맥에 과거 F40 보고서의 답변 요약이 노출됐다. 그 내용은 이번 실행 입력에 넣지 않았고 현재 응답을 미리 보거나 새 채점자에게 전달하지 않았다. 채점 패킷과 새 채점자는 아예 만들지 않았다. 원시 이벤트·숨은 추론·자격 증명·보호 설정 내용은 읽지 않았다.

현재 변경에 해당하는 원래 완료 통계·안전한 보존 영수증·입력 및 최종 해시·README 역변환과 최종 기록 확인을 수행했다. 동일 실행기의 기존 전체153개 테스트 중147개 통과·환경 제약6개 건너뜀·실패0개 증거를 재사용했다. 새 전체 테스트·수학 재실행·실행기·스킬·방법론 변경·설정 변경·로컬 보관·푸시는 없다. 요청 모델은 Sol이고 실제 처리 백엔드는 호스트가 증명하지 않아 미확인이다. 추론 수준은 난도·판정·중단의 고려 사항이 아니다. F41의 실제 난도는 미확인이고 확보0/6개로 전체 목표는 미완료다. F32 이후 최종 산출물 독립 검토와 보관은 유보 상태다.
