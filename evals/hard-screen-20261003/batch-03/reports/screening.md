# Batch03 선별: 세 문제군 모두 제외

서로 다른 세 판단 문제를 실제 선별했다. 각 문제의 C/H 쌍, 정답과 대안 허용 기준을 두 차례 독립 검토한 뒤 동결했다. H는 작성자가 보았으나 선별에는 쓰지 않았다.

| 문제군 | 핵심 판단 | 채점 A/B | 완전 통과 |
|---|---|---|---|
| F11 | 공동 성공 보수의 전원 포기 가능성을 없애는 계약 | 각각 9·10·10 | 3/3 |
| F12 | 같은 미지의 유형이 모든 분기를 지배하는 정책의 최악 기대값 | 각각 9·10·9 | 3/3 |
| F13 | 개별 참여율과 공동 전달률을 구분해 실제 공동 신호 설계 | 각각 10·10·10 | 3/3 |

F11 응답들은 한 작업의 독립 증명에 보수를 연결하여 상대가 포기해도 작업할 유인을 만들었다. F12는 두 고정 유형에서 모두 기대값 6을 달성하고 최적임을 증명했다. F13은 개별 참여율 8/9와 공동 전달률 7/9를 구분하고, 공개 공통 신호의 상한 2/3까지 계산했다.

감점은 설명 또는 예약 시한 명시의 누락이며 실질적 판단 오류가 아니다. 세 문제군 모두 사전 난도 기준을 충족하지 못했다. 두 채점자는 새 문맥에서 조건 표시를 생략한 동일 자료만 받았다. 이 선별에는 비교할 스킬 적용 조건이 없으며, 스킬 효과를 주장하지 않는다.

실제 9개 세션과 원문을 보존했다. 셸 호출이 280초 후 반환되었을 때 8개 완료 메시지만 있었지만, 원래 실행기가 마지막 실행과 정리를 마쳤다. 최종 slot 기록 9개, 원문 해시, 프로세스 종료·임시 인증 복사본 제거·원본 보존을 모두 확인했다. 재실행·대체·강제 종료는 없었다. 향후 전체 실행 호출 시간은 개별 실행 제한의 합과 정리 여유를 포함해야 한다.

코드 f33931f와 해당 문항에 묶인 중립 입력 canary를 사용했다. 요청 모델은 gpt-6-sol이며 실제 백엔드는 확인되지 않았다. 추론 수준은 선별·중단 기준이 아니다. 원문·두 채점·안전한 실행 증거는 responses.json, grades.json, evidence.json에 있다.
