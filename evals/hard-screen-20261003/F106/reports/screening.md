# F106 선별 결과

**F106은 난도 채택 기준을 충족하지 못했다.** 원래 세 답변 모두 실행 조건을 통과했고, 두 독립 채점자가 각각 10·10·10으로 평가했다. 객관적 결정 오류와 적격 판단 실패는 모두 0개다. 같은 응답 최소 2개에서 적격 실패가 있어야 하는 기준에 미달한다. ROOT FINAL 검증으로 제외를 확정했으며, 확보한 어려운 문제군은 계속 0/6개다.

세 답변은 모두 제한 공개를 선택하고, GO이면 기본 지급 0·한 운영자에게 단독 참여 보증 3·준비금 3으로 운영하며 STOP이면 닫는 정책을 제시했다. 모든 균형에서 참여를 유도하고, 기대 순가치 8.3과 나머지 정보 서비스의 비교값 7.4·6.5·7.2를 정확히 계산했다. 대칭·비대칭의 동등한 합법 계약도 사전 기준상 허용했다.

원문항은 정적 정보 한 번 전달로 실행했다. 원래 순서 2→3→1에서 각각 새 세션의 문제 차례 1개·최종 답변 1개를 보존했으며, 재시도·교체·재실행은 없었다. 중립 시험 두 건은 별도로 두며, 둘 다 정확히 ready를 반환했다. 입력·문맥·스킬 노출 구분·격리·원본 보존·도구 미사용·프로세스 종료·인증 사본 정리 조건을 실제 기록으로 확인했다. 요청한 모델은 gpt-6-sol이며 실제 백엔드 신원은 검증되지 않았다. 추론 수준은 판단 기준에 사용하지 않았다.

두 새로운 독립 채점자는 각각 같은 익명 자료만을 실질적 근거로 사용했다. 두 FULL FIRST 원본과 전체 래퍼를 저장하고 바이트 재확인한 뒤에만 대응표·원문을 읽고 종합했다. 두 채점자 모두 허용된 일반 절차 파일 6개와 도구 발견용 메타데이터만 추가로 읽었다고 밝혔다. A 전달문에는 기존 허용 경로 한 줄이 중복됐지만 추가 권한이나 실질적 정보는 없었다. 실제 전달문·차이·원문을 보존했고 ROOT가 이 제한을 검토했다. 채점자 교체·재채점은 없다.

준비 중 수정 작업의 사전 실행문 기록에서 이스케이프 손상이 발생했다. 손상본과 실제 반환 원본을 보존하고, 반환 기록은 base64 바이트 쓰기와 전체 읽기로 복구했다. 실행문 재구성은 사후 기록이며 사전 저장의 증거로 취급하지 않는다. 작업을 다시 실행하지 않았고, ROOT는 이후 고정된 후보·네 정적 실행 기록·현재 해시를 확인한 뒤 시험을 승인했다. 중립·원문항·수집기·익명 자료 생성의 실제 실행문은 실행 전에 저장·재확인했고, 전체 반환도 원본 그대로 보존했다.

미사용 H는 사전확률과 보고 규칙이 다른 근접 전이 문항이며 동일 난도라고 주장하지 않는다. K는 나쁜 상태의 사적 손실만 바꾼 설명용 대조다. H/K 실행과 점수를 매기는 스킬 적용 비교는 하지 않았다. 결과는 이 고정된 유한 메뉴 문항의 선별 결과이며, 일반 영역 전체의 쉬움이나 스킬 효과를 증명하지 않는다.

확인된 누적 하한은 후보 식별자 90개·보존된 최종 문제 출력 파일 259개·완료 문제 차례 318개다. 이전에 미확인으로 남긴 기여는 그대로 미확인이며 0으로 가정하지 않았다. 신규 중립 차례 2개를 문제 집계에 넣지 않았다. 이 원시 출력 파일 수에는 실행 오류가 난 과거 파일도 포함되므로 유효 평가 횟수와 같지 않다. 최종 전체 검증과 유보된 산출물 검토는 실제 여섯 문제군 확보 뒤에 수행한다.
