# F158 — INCOMPLETE_PROTOCOL

F158 / source-pair-2는 세 원본 모두 필요한 증거가 `UNVERIFIED`여서 `INCOMPLETE_PROTOCOL`이다. 채점 `NOT_RUN`, 난도 `UNKNOWN`, 유지 증가 0개·누계 **0/6**이다. 종료 기록 상태는 `PENDING_ROOT_FULLCHECK_AND_FRESH_REVIEW`이며 최종 승인을 주장하지 않는다.

독립 의미 감사 (local retained evidence; not published)는 실제 제출의 비문구 인수와 성공 결과·고유 원본 연결, 요청 및 관측 구성 `gpt-6.1-sol / medium / fork_turns:none`을 확인했다. 그러나 실제 호출의 message는 1,740바이트 보호 표현이고 동결한 의도 문구는 1,177바이트다. **정확한 실제 제출 문구의 일치는 미확인**이며, 다른 평문이 제출됐다는 증거도 아니다. Pretrial (local retained evidence; not published)과 launches (local retained evidence; not published)는 의도·부모 기록이고 독립적인 실제 인수 증명을 대신하지 않는다. 선언된 API 의미와 보호된 초기 전달 평문의 예외도 실제 제출 인수 증명 누락을 면제하지 않는다.

감사는 전체 관측 문맥의 기록 종류와 구조·해시를 확인했지만 모든 지침·기억·스킬 목록과 world_state의 **전체 의미 검토는 완료하지 못했다**. 공통 문맥 11부분 77,799바이트의 일치나 제한된 문자열 검색은 문맥 승인 또는 오염 배제 증거가 아니다. 따라서 세 슬롯의 제출·문맥·종합 판정은 모두 `UNVERIFIED`다. 실제 backend·fallback·내부 격리와 보호된 초기 평문도 미확인이다. 공유 파일시스템이며 완전한 격리를 주장하지 않는다.

한편 각 슬롯의 완전한 C 수신(1,214바이트), 관측된 행동, 정확한 최종 답변 보존은 감사 범위에서 `VALID`다. 실제 읽기 wrapper는 동결 448바이트에 끝 LF 한 바이트만 추가된 449바이트이고 중첩 인수는 정확히 같다. 감사는 완결된 문장 뒤 공백이 입력·명령·행동을 추가하지 않는다고 확인했으므로 semantic v3의 사전 명시된 표현 차이 허용을 적용한다. 바이트 동일성으로 바꾸어 기록하거나 이 설명으로 제출·문맥 미확인을 해소하지 않는다.

계획·실제 원본은 단일 턴 3개이며 각 최종 답변 1개씩 총 3개와 공개 기록 21개를 기존 공개 보존본 (local retained evidence; not published)에 미채점 상태로 보존했다. 원본 최종과 표시 사본 두 개는 슬롯별로 같다. 원본은 기존 제한된 소스 위치에서 변경 없이 유지되며 이 종료 작업은 원본 세션을 다시 열거나 복사하지 않았다. [검증 기록](verification.json)은 공개 텍스트의 실제 UTF-8 해시와 감사가 확인한 원본 해시를 구별한다.

익명 채점 패킷은 **PREPARED_NOT_RELEASED**이다. 준비 기록 (local retained evidence; not published)의 동결 상태 `PREPARED_CONDITIONAL_NOT_DISPATCHED_NOT_GRADED`를 그대로 보존한다. 세 원본 모두 VALID라는 조건이 충족되지 않아 채점자 전달·호출·채점은 0회다. 점수·객관적 결정 오류·적격 inquiry failure·공동 실패 ID는 판정하지 않았다. 재시도·대체·후속 요청·추가 문제 턴·H 실행·중립 검사·스킬 비교·채점 처치는 모두 0회다. H는 작성자·소스 검토자가 보았으나 참가자와 채점에는 사용하지 않았다. 난도·가족 독립성·스킬 효과를 주장하지 않는다.

접근 편차도 보존한다. 수집 기록 (local retained evidence; not published)은 일반 지침 출력과 보호 문자열 일부 출력이 있었다고 보고한다. 감사는 수집자 본문에 접근하지 않아 실제 출력 전체 범위를 독립 확인하지 않았다. 지속 증거에서 조각을 제외해도 이미 발생한 출력은 없어지지 않는다. 감사자도 한 차례 부모 파일 전체 바이트를 메모리에 읽은 뒤 허용 마지막 구간만 잘라 비교했다. 범위 밖 본문을 파싱·검사·출력하지 않았지만 읽기 구현은 허용 범위보다 넓었고 이후 위치 지정 읽기로 수정했다. **참가자 오염이나 원본 변경을 입증한 편차는 아니며, 완전한 개인정보 보호 준수도 주장하지 않는다.**

채택 기록 (local retained evidence; not published)이 semantic v3와 collection v1을 선택한다. 소스 검토 C (local retained evidence; not published)·D (local retained evidence; not published)의 승인은 source-pair-2 소스 유효성에 한정한다. 사전 명령 검토·정적 검사·패킷 준비는 실행 수용이나 난도 증거가 아니다. Pretrial의 실행 전 대기/0회, source freeze/protocol, collection 및 blind 준비 기록의 과거 대기 상태를 수정하지 않는다. 현재 결론은 별도 종료 기록에만 남긴다.
