# F34 선별 결과

**제외. 두 독립 채점자가 결정 오류2개와 적격 실패1개를 같은 응답에서 확인했다. 적격 실패는 R03 한 개로, 사전 요구인 동일 응답 최소2개에 미달한다. 채점은10·7·4와10·7·7이며 확보한 어려운 문제군은 여전히0/6개다.**

## 원자료와 사전 검증
앞 장치의 물리적 이동이 뒤 장치의 관측 대상도 바꾸는 유한 운영 문제를 새로 만들었다. 앞 장치는 현재 위치 X를 보고 이동u를 정한다. 뒤 장치는 이동 후 위치 Z=X+u의 잡음 섞인 화면 Y만 보고 최종 이동b를 정한다. 두 이동 비용과 최종 위치 오차 비용을 합친 기대비용을 최소화하고 예산23/25 이하일 때 가동을 승인한다. 추가 모듈 D9는 정확한 현재 Z를 제공하지만 건당3/10 비용을 더한다. 공짜 기록 분석과 계산은 가능하며 현재 기록은 장치의 실행 뒤에 도착한다.

참가자 기록에는 시각·입력 포트·수식·비용·목적만 제공했다. 정답 표, 미리 계산한 최솟값이나 정보를 전달하는 방법에 관한 풀이 설명은 주지 않았다. H는 화면이 앞 장치의 이동 전 X를 측정하는 구조적 상대 문항이다. 같은 예산에서 H는 실제로 가동 불가지만 최소비용 정책을 찾고 그 결과를 보고할 수 있어 불가능한 가동을 요구하지 않는다. K는 정확한 Z 입력이 이미 설치된 대조다. H/K는 참가자에게 실행하지 않았다.

작성자는 앞 장치의 표78,125개와 각 관측에서 가능한 뒤 장치 명령15개를 모두 실제 탐색했다. 별도의21개 입력·잡음 결과 추적으로 비용 항목도 확인했다. 두 원자료 단독 검토자가 각각 독립적인 정확 정수 탐색으로 C51/56, H131/140, D973/70, K26/35를 복원했다. 초기 기록에서 ID가 위치 정보를 담을 가능성과 개인 난수의 독립성이 충분히 명시되지 않은 점을 발견했다. ID를 입고 전 일련번호로 부여하고 위치·잡음·ID와 모든 난수의 독립성을 명시한 뒤 두 검토자가 다시 읽어 확인했다. 물리 제어·비용·목적은 바꾸지 않았다.

첫 전체 검토는 한 문항의 채점 항목이 참가자에게 주어지지 않은 다른 문항의 사실까지 요구하는 문제를 찾았다. 해당 문항에 제공된 사실만 평가하도록 수정하고 별도 최종 검토가 정확한 수정본을 승인했다. 원래 검토 결과와 해시는 보존했다. 최초 설계 보고서의 무이동 비용 항목143/140+3/7은 잘못됐으며 원문과 별도 정정19/20+1/2를 함께 그대로 보존했다. 총비용29/20과 정책 비교는 바뀌지 않았다. 이 정정은 참가자 응답이나 사후 기준 변경이 아니다.

## 실제 응답과 채점
R01은 전체 유한 탐색, 실제 관측별 뒤 장치 명령 선택, 두 모드 비교와 예산 판정을 하는 완전한 실행 절차를 제시했다. 정확한 원래 Python 코드를 메모리에서 실행하자 S6비용51/56, D9비용73/70, S6선택과 가동 승인YES를 출력했다. 특정 소수나 정답 표를 본문에 미리 나열하지 않았다는 이유로 틀렸다고 처리하지 않았다.

R02의 실행 절차도 같은 S6선택과 승인True를 출력했지만 본문은 가동하지 말라고 권고했다. 두 채점자는 이 모순을 결정 오류로 확인했다. 다만 S6의 모든 정책에 대한 거짓 하한이나 잘못된 입력·상태 전제를 명시했다고 단정할 증거가 부족했다. 정확한 D9가 항상 더 낫다고 생각했을 것이라는 숨은 전제를 만들어 적격 실패로 추가하지 않았다.

R03은 S6의 가장 좋은 합법적 정책도 D9보다 비싸다고 명시하고 `assert s6_score > d9_score`를 넣었다. 원래 코드의 탐색은 S6점수255와 D9점수292를 계산한 뒤 이 거짓 assertion에서 멈췄다. 두 채점자는 동일하게 명시적 거짓 전체 하한의 적격 실패로 판단했다. 전체 제약을 지키는 S6표의 비용51/56은 예산 이하이며, 실제 모드와 장치 표 및 가동 거절을 바꾼다. 이 반례는 D9의 올바른 비용73/70을 단순히 고치는 것이 아니다.

R03의 항목별 점수는 A4, B7로 달랐다. 원래 점수와 설명을 보존했으며 평균이나 재채점으로 맞추지 않았다. 두 채점 모두 R02·R03을 결정 오류로, R03만 하나의 적격 오류로 판단했다. R01은 올바르므로 전 응답 실패 때 필요한 추가 타당성 검토 조건도 발생하지 않았다. 스킬 비교는 수행하지 않았다.

## 증거와 한계
새 중립 검증2회 뒤 원래 C 세션 세 개를 각1회 실행했다. 외부 호출은300초에 반환되지 않았지만 원래 실행기는 계속 작동했고 모든 슬롯이 원래 첫 시도에서 완료됐다. 재실행·응답 교체·도구 시도는 없다. 동결 입력, 실제 전달 본문과 확인 기록, 공통 문맥, 최종 원문 해시, 프로세스 종료와 임시 인증 사본 제거를 확인했다.

익명 패킷은 빈 구조에서 현재 C문항·사례별 채점표·동결된 의미 기준·읽어 확인한 일반 규칙·원래 답만 조립했다. 최초 검사에서 현재 D9비용26/35를 이전 사례 숫자로 잘못 탐지했으므로 검사 범위를 사례 ID와 조건 정보로 수정했다. 입력·패킷·답은 바꾸지 않았다. 최종 readback을 마친 패킷 SHA256은d3bbb585ad2ccb8c1935a515213258760d09ccd11adf93cbcc24bade3d7eb161이다.

두 새 문맥 채점자는 패킷만 읽고 독립적인 메모리 내 Node 전체 탐색으로 비용·반례를 확인했다. 채점자의 환경에서는 원래 Python 코드 실행이 불가했으며 이 한계를 명시했다. 작성자의 정확한 원래 Python 실행과 채점자의 독립 수학 검증은 별도 증거다. 작성자 결과는 채점자에게 전달하지 않았다. 동결된 v2/v3 기준은 변경하지 않았다.

누적30개 실제 문제군·최종 출력90개·모델 차례131개다. 형식 무효1개와 문항 모호성3개는 별도로 보존한다. 적격 실패 한 응답은 실제 근거지만 문제군 확보 조건을 충족하지 못해0/6 목표는 미완료다. 실행기·스킬 변경이나 새 전체 테스트는 없으며 기존153개 테스트 중 환경 제약6개 제외·실패0개 기록을 재사용했다. 실제 백엔드는 확인되지 않았고 추론 수준은 고려 사항이 아니다. 최종 산출물 검토 두 차례와 보관 커밋은 전체 자료 안정 이후로 유보 상태다.
