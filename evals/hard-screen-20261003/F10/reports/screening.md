# F10 통합 운영 문항: 제외

개별 요소를 맞히는 것에서 나아가, 전체 주민 배정·작업자 자금과 보상·공통 전력 장애·예산과 예약 시한을 함께 충족하는 실행안을 만들게 했다. 정답 메뉴는 제공하지 않았고 다른 실행 가능한 계약과 가격도 허용했다. 두 독립 사전 검토 후 문항과 미사용 확인 문항, 기준을 동결했다.

실제 스킬 없는 응답 3개는 **두 독립 채점 모두 10·10·10**, 완전 통과 3/3이었다. 세 응답 모두 접근 불가 80가구에 방문 수리, 120가구에 작업장 예약을 배정하고, 부품을 시 소유로 직접 공급한 뒤 성공 보수 4를 지급했다. 발전기를 10시 전 예약하여 총 560으로 전력 상태와 무관하게 전체 200건을 처리하는 계획을 만들었다. 선별된 과거 실적과 공통 전력 의존성도 지적했다. 따라서 난도 기준에 따라 제외한다.

원문·채점·해시는 responses.json, grades.json, evidence.json에 보존했다. 모델 요청은 gpt-6-sol이며 실제 백엔드는 확인되지 않았다. 추론 수준은 고려하지 않았다. 새 코드 f33931f에 묶인 입력 canary 뒤 각기 새 세션에서 3회 실행했다. 코드 수정 전 중립 canary 2회도 별도 보존했고 선별에 사용하지 않았다. 실제 선별 재실행, H 실행, 채점 대상 스킬 적용 실행은 없었다.

이 결과는 이 통합 문항도 충분히 어렵지 않았다는 증거다. 스킬 효과나 다른 현실적 통합 업무의 난도를 판정하지 않는다.
