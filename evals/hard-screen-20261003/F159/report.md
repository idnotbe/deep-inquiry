# F159 — EXCLUDED_NOT_HARD

Issue #10 · source revision 1 · closure-1 · **PENDING_ROOT_FULLCHECK_AND_FRESH_REVIEW**.

독립 의미 감사가 세 원본을 모두 VALID로 판정한 뒤 공개된 동일 패킷을 채점한 두 결과는 R1/R2/R3 순서로 각각 **10/10/10**이다. 두 결과 모두 객관적 결정 오류와 적격 탐구 실패가 전부 false이며, 같은 응답 ID의 공동 적격 집합은 **[]**다. 최소 두 동일 ID가 공동 적격이어야 하는 보존 조건을 충족하지 않아 **EXCLUDED_NOT_HARD**로 정리한다. 유지 증가 **0**, 누계 **0/6**. 이는 이 사례·세 원본의 선별 결과이며 일반적 능력이나 스킬 효과의 결론이 아니다.

## 실제 답안과 판정 근거

세 답안은 모두 첫 방문 영수증을 구매하고 첫 고객의 유형별 자발적 A/B 선택, 실제 서비스·편익의 연결 기록으로 상태 식별, 둘째 고객부터 상태 공개와 유형별 추천표를 제시했다. 센터가 이후 고객의 유형을 수집할 필요는 없다. 첫 방문 기대 편익 10, 이후 방문당 13, 비용 12로 **10 + 19 × 13 − 12 = 245**, 달성 가능한 최적값 245 대비 실제 손실은 **0**이다.

- R1: “센터는 고객 유형을 미리 알 필요가 없다.”
- R2: “과거 기록에 따라 메시지를 바꾸거나 독립 난수를 사용해도 설정에 관한 정보가 생기지 않는다.”
- R3: “모든 도달 가능한 기록에서 센터와 현재 고객의 설정 확률은 계속 반반으로 남는다.”

세 답안은 익명 편익 관측의 비식별성, 유인 없는 K 추천의 실패, 연결 기록 하나의 충분성, 상태 공개만으로 후속 최적 선택을 구현하는 정책과 전체 편익 상한을 모두 처리했다. 이번 설계가 기대한 해당 공개 실패는 관측되지 않았다. 이 교정은 F159에만 적용하며 메커니즘 전체의 난도를 부정하거나 과거 결과를 재분류하지 않는다.

소스 검토 B의 **P2는 유지한다**. 계약별 200/245/227은 달성 가능한 최대값이며 실제 제출 정책의 성과가 자동으로 그 값이 되는 것은 아니다. 등록만 구매하고 상태를 전달하지 않으면 순성과는 170일 수 있다. 이번 두 채점은 실제 영수증 분기와 상태 공개, 고객의 최적 반응을 검토한 완전한 정책에 대해 245와 손실 0을 계산했다. 다섯 구성 점수는 각각 2점이며 숫자 점수는 동일 ID의 의미상 적격 판정을 대신하지 않는다.

## 실행·증거와 보존

채택된 v4, 남아 있는 v3/수집 절차, 방법 v2/v3를 동결 pretrial에 연결했다. 독립 감사는 원본당 시작·완료·턴 각각 1개, 승인된 읽기 1개, 정확한 C 수신과 최종 답안 보존을 확인했다. 요청은 native gpt-6.1-sol / medium / fork_turns:none이며 참가자 자체 설정과 실제 비메시지 호출 인자가 일치했다. 실제 wrapper의 끝 LF 하나는 의미상 허용되었고 원문 사본은 유지됐다. 대상 deep-inquiry 스킬을 제공·호출하지 않은 검토된 공통 운영 환경의 기준선이다. 공통 지침이 없는 환경이라는 주장은 하지 않는다.

원본 3개·문제 턴 3개·채점 결과 2개. 재시도, 대체, 후속 요청, 추가 문제 턴, H 참가자 실행, 중립 비교, 스킬 비교, 점수 비교 처치는 모두 **0**이다. H는 작성자·소스 검토자가 본 자료이며 참가자·채점에는 사용하지 않았다. 스킬 효과는 **UNKNOWN_NO_COMPARISON**이다.

`collection-manifest.json`의 UNGRADED/PENDING, blind manifest의 NOT_RELEASED 및 source freeze의 과거 대기 문구를 수정하지 않았다. 현재 독립 감사와 `f159-grading-release.json` 및 두 채점 결과가 후속 상태를 기록한다. 원본 사본과 의미 감사에 기반한 유효성 판단을 새 채점이나 새 시행으로 바꾸지 않는다. F158의 INCOMPLETE_PROTOCOL과 과거 기록은 그대로다.

## 편차와 미확인 범위

교정 리허설 B의 준비 오류 출력에 불필요한 로컬 경로가 포함된 P2, 선행 리허설 A의 FAIL, 의미 감사자의 기억 조회 출력에 불필요한 과거 위치·식별자가 포함된 P2를 보존한다. 수집자의 긴 명령 전송 실패와 수정 이력도 기존 manifest에 남는다. 이 준비·감사 편차를 참가자 오염의 증거로 바꾸지 않으며 과정 전체의 완전한 개인정보 최소화 준수도 주장하지 않는다.

부모는 이미 범위를 제한한 캡처로 채점자 원본 최종 결과를 추출해 grade-a/b.json에 저장했다고 확인했다. 이번 마감 작업은 그 기존 증거와 중립 패킷을 사용하며, 지정 범위의 채점자 헤더도 확인했다. 추가 전체 세션 읽기·파싱 제안은 자동 승인 검토가 제외된 비공개 추론·보호 초기 내용 접근 위험으로 거부하여 실행하지 않았다. 우회하지 않았으며, 마감 작업자 자신이 원본 최종 결과를 다시 대조하거나 추가 공개 행동·fresh 턴 수·다른 파일 미열람을 독립 검증하지 않았다는 한계다. 기존 원본 캡처의 부재나 무효를 뜻하지 않는다. 안전한 헤더 해시와 확인 범위는 closure/grader-provenance.json에 기록한다.

보호된 초기 평문은 v4의 root/native-API 신뢰 가정이며 독립 동등성 증명이 아니다. 실제 backend/fallback, 비공개 bootstrap, 완전한 내부 격리는 미확인이다. 공유 파일시스템은 격리되지 않았다. 가시 기억 생략과 불투명 참조의 한계도 독립 감사대로 유지한다. 노력 수준은 보존 판단 근거가 아니다.
