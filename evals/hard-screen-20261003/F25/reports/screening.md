# F25 실제 선별 결과

**채택하지 않았다.** 원래 세 응답 가운데 두 개는 실행 가능한 최소40 차입 정산을 제시했고, 한 개는 채권 보유자와 이전 방향을 뒤집어 실행할 수 없는 지시를 냈다. 두 독립 채점은 모두10·10·8, 적격 탐구 실패0개로 일치했다. 잘못된 지시를 정답이나 난도 증거로 바꾸어 기록하지 않는다.

F25는 현금표·송장·은행 처리 규정·서명된 채권 이전 조항으로 구성한 새 원본 사례다. 두 사전 검토자는 oracle을 보기 전에 참가자 자료만으로 각각 C40/H70/K80을 복원했다. 이후 첫 대조에서 자기 채권 취소가 없는 동등한 최적 경로를 발견해 이를 허용하도록 채점표를 수정했고, 다른 검토자가 최종 입력을 승인한 뒤 동결했다. 계약이 작고 명확하게 구조화되어 있어 여전히 쉽게 풀릴 수 있다는 한계도 사전에 기록했다.

| 응답 | 실제 지시 | A/B | 객관적 실행 오류 | 사전 적격 실패 |
|---|---|---|---|---|
| R01 | Harbor→Alder→Birch→Cedar로40 채권 이전, Cedar 취소,40 차입 후60/40/20 지급 | 10/10 | 없음 | 없음 |
| R02 | 같은 합법적 경로와 순액60−초기현금20 하한 | 10/10 | 없음 | 없음 |

R03은 최초 이전부터 권한이 없고 후속 대체 송장도 생성되지 않는다. 양 채점자는 이 하나의 역할 역전을 mechanism에서 한 번 감점했다. 차입40은 맞고, 합법적 최적안보다 높은 보편 하한이나 자금 없는 상계를 주장하지 않았으므로 동결된 의미 기준에는 해당하지 않는다. 오류의 숨은 원인을 추정하지 않았고 실행 후 기준을 넓히지 않았다. 점수8 이상·critical0이라는 보조 수치식은3개 모두 충족하지만 실제로 유효한 정산은2개뿐이다.

채점 자료의 결함도 보존한다. 조건·모델·호스트 정보는 제거했지만, 일반 기준 끝에 이전 F24의 `anywithin60legalinternalplanacceptable` 문장이 잘못 남았다. F25 문제·채점표·의미 기준은 최소40 정산으로 정확했고 양 채점은40을 적용했으나, 이 불필요한 문구 때문에 완전하게 구성된 채점 패킷이라고 주장하지 않는다. 원래 패킷·두 채점·세 응답을 유지하고 재채점하거나 재실행하지 않았다. 두 채점자는 사후 확인에서 해당 잔여 문구가 최소40·실행 오류·적격 여부 판단에 영향을 주지 않았다고 각각 밝혔다. 이는 채점자 확인이며 패킷 결함 자체를 없애지는 않는다.

세 원래 단일 턴 실행은 모두 완료됐다. 입력 읽기 확인, 최종 응답 해시, 프로세스 종료, 원본 보존과 임시 인증 복사본 제거를 확인했다. 입력과 oracle 해시는 실행 전에 고정했고 새 중립 canary 두 개가 READY로 완료됐다. H/K는 작성자·검토자가 본 미사용 문항이며 실제 문제의 스킬 적용 실행은0회다. 요청 모델은gpt-6-sol, 실제 백엔드 확인은 불가하며 추론 수준은 선정 고려 사항이 아니다.

현재 누적21개 실제 후보 문제군, 최종 출력63개, 문제 모델 차례104개다. F15 형식 무효1개와 F19 문항 모호성에 속한3개를 따로 구분한다. 확보한 어려운 문제군은0/6개이며 목표는 미완료다.
