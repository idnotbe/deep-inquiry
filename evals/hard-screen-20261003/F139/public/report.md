# F139 — EXCLUDED_NOT_HARD

세 원본 응답 모두 자발적 계약을 선택했다. 두 독립 FIRST 채점은 각각 10/10/10이며, 객관적 결정 오류 0/3, 채택 요건에 맞는 탐구 실패 0/3, 함께 지목한 실패 응답 집합은 빈 집합이다. F139는 EXCLUDED_NOT_HARD이고 유지된 가족은 0/6이다. 여섯 가족 목표는 미완료다.

정답은 100개 사이트당 보장 순가치 £56,000의 자발적 계약이다. 전체 미사용은 £50,000, 중앙 활성화는 최저 £44,000이다. 세 응답은 선택된 참여자의 80%와 전체 대조군의 50% 비교가 전체 활성화의 인과효과를 확립하지 못한다는 점도 정확히 설명했다.

F139부터 사전에 채택된 직접 native 하위 에이전트 경로를 사용했다. 원본 세 슬롯은 각각 새 문맥을 요청하는 fork_turns:none, 요청 모델 gpt-6.1-sol / medium으로 실행되었고, 동결된 C와 공통 지시만 부모가 전달했다. 도구 시도 관측은 0이나 전체 도구 이력은 제공되지 않아 미사용을 검증한 것은 아니다. 실제 백엔드, 호스트가 추가한 문맥과 격리는 확인되지 않았다. 과거 CLI의 시작 검사·중립 자격 검사·전역 소스 보호 검사 실행을 주장하지 않는다. 노력 수준은 판정 근거가 아니다.

최초 응답 세 개와 독립 FIRST 채점 두 개를 그대로 보존했다. 익명 패킷은 문제·응답 문자열 일치와 노출 표식 부재를 검증했다. 후속 직접 검증에서 FIRST 전체 문자열, 답변 인용 30개, 동일한 공통 입력, 요청 설정과 원본 소스 해시가 모두 일치했다. 채점자 B는 일반 코드 관련 역할 지침 두 개를 읽었다고 보고했다. 조건 정보 누출 증거는 관측되지 않았으나 무균 문맥이었다고 주장하지 않는다.

H 참여자 미사용, 점수 비교용 처치 0회, 재시도·대체 0회다. 스킬 효과는 UNKNOWN이다. F138은 INCONCLUSIVE_RUNTIME으로 남고 F127은 변경하지 않았다. 이 기록은 ROOT 최종 읽기 검증 전의 로컬 전달본이다.
