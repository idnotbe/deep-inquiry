# F142 — EXCLUDED_NOT_HARD

두 독립 FIRST 채점은 원본 세 답변에 각각 10/10/10을 부여했다. 각 채점의 objective_decision_error와 qualifying_inquiry_failure는 모두 0/3이고, 공동 실패 답변 집합은 []이다. 이번 후보는 채택 요건을 충족하지 못했으며 유지 수는 0/6이다.

세 답변 모두 A 액추에이터만 4,000크레딧에 교체하는 최저가 설치를 찾아, 모든 허용 입력·카메라 오차에 대해 최종 오프셋 0을 보증했다. 원본 2·3(R01·R02)은 A가 입력을 정수 위치로 옮기고 B가 카메라 값을 같은 정수로 복원한다. 원본 1(R03)은 네 중심값 {-1.5,-0.5,0.5,1.5}와 구간별 규칙을 사용했다. 두 방식 모두 이동 한도와 오차 끝점을 지키며, 실제 도달 가능한 관측에서 B 명령이 합법이다. 참고 해법과 다른 네 중심값 구성도 동등한 정답으로 인정됐다.

기존 장비가 어떤 허용 프로그램으로도 보증할 수 없다는 증명도 세 답변 모두 제시했다. 동일한 이전 이력·일련번호·지원되는 시드를 고정하고 X=0과 X=0.5를 비교하면 A 이동 후 위치 차이는 0.3~0.7이다. 허용 카메라 오차로 두 경우의 관측을 같게 만들 수 있지만, 같은 B 명령으로 둘 다 오차 0.1 이내에 두려면 차이가 0.2 이하여야 하므로 모순이다. 이는 특정 선형 제어기의 실패가 아니라 허용된 임의·불연속 규칙을 포괄하는 비교다.

F34의 R03은 관측을 올바르게 모델링하고 S6·D9 비용을 계산한 뒤에도 S6가 더 비싸다고 주장한 명시적 거짓 보편 비교로 설계에 착안을 제공했다. F142가 새로 가정한 카메라 교체 필요성 오류는 F34에서 관측된 오류가 아니며, 이번 세 답변에서도 관측되지 않았다. F34 원본을 재사용하거나 재채점하지 않았다. 이 결과는 이번 문제와 세 원본의 관측이며, 전체 정보전달 메커니즘의 난도나 목록 전체의 고유성, 스킬 효능을 입증하지 않는다.

원본은 세 개의 새 native 문맥에 gpt-6.1-sol / medium, fork_turns:none을 요청한 실행이다. 요청·응답과 고정 소스의 연결은 검증했지만 실제 백엔드, 호스트 추가 문맥, 전체 도구 미사용은 미확인이다. 과거 CLI 자격 검사를 수행했다는 주장은 없고, 노력 수준은 판정 근거가 아니다. H는 원문 검토자가 본 미사용 문제로, 참여자 실행과 채점에 사용하지 않았다. 원본 3회, 재시도·대체·중립·스킬 비교 호출 0회이며 스킬 효과는 UNKNOWN이다.

두 원문 검토는 유효성을 승인했고 중대 차단 사항은 없었다. 보조 스크립트의 자연어 문장 고정 검사는 MEDIUM 권고, 함수 타입 표기와 사용 메타데이터 누락은 LOW 권고로 보존했다. 독립적인 수학적 증명을 무효화하는 결함으로 판정하지 않았으며, 고정 소스는 수정하지 않았다. 패킷 준비의 도구 시작 실패, 실행 도구 부재, 과대 저장 요청 거절, 검사 명령 구문 오류와 표식 검사 오탐은 deviations.md (local retained evidence; not published)에 각각 기록했다. 이 준비 실패는 모델 재시도나 평가 재실행이 아니다.

두 FIRST 결과의 전체 원문과 20개 인용문을 확인했고, 소스·검토·원본·익명 패킷·대응표·채점·실제 검증 기록의 해시를 [evidence.json](evidence.json)에 연결했다. 익명 패킷은 최초 생성부터 최종 검증 이후까지 변경하지 않았다. 네 공개 파일과 README의 원래 바이트 및 추가 부분은 temp/hard-screen-20261003/worker/F142/final/manifest.json에 고정했다. 자체 검증 기록은 같은 디렉터리의 verification-actual.json이다. 현재는 ROOT의 읽기 검증과 독립 전달 검토를 기다리는 로컬 기록이며, ROOT 최종 승인을 주장하지 않는다.
