## 문제와 사전 검토

초기 의뢰는 결과가 감소했다는 공급업체 rollback 제안과5개 기록 색인을 제공했다. 실제 기록은 렌더링으로 바뀐 output count가 보고서의 포함 여부뿐 아니라 운영 승인 어댑터 입력에도 쓰임을 정의한다. 보고서만 고치거나 CURRENT6항목을 모두 적격으로 승인하는 것은 인증 입력을 대신하지 못한다. 원문은 C (local retained evidence; not published), 미사용 H (local retained evidence; not published), 올바른 실제 행동 대조 K (local retained evidence; not published)에 있다. H는 실행 전 LEGACY boot_count를 유지하는 관측 구조로 무료14가 가능하다. K는 이미 설치된 인증 입력으로 유지 승인14/0이 맞고 대시보드 근거만 부적절하다. H/K 참가자 실행은 없다.

두 새 독립 원문 복원 이후 같은 독립 A/B가 안정된 묶음을 병렬 전체 검토했다. 최초 전체 결과 둘 다 입력 구분자를 문자 그대로의 backslash-n으로 잘못 적은 설명 한 건에 REVISE였다. 실제 실행기 함수는 LF 두 개(0a0a)를 사용한다. 설명과 연결 해시만 수정하고 최초 원문 및 별도 같은 수정본 APPROVE를 모두 보존했다. 먼저 oracle의 K 확인 시점도 원문대로 tick0, 실행 전으로 한정 수정했다. 법칙·문항·방법·실행기는 바꾸지 않았다. 이는 실제 문제 실패나 네 명의 새 전체 검토자 승인이 아니다. READ 자체는 F09/F23에도 있었으므로 새로운 기능이나 그 자체의 난도로 주장하지 않는다.

## 실제 입력·환경·집계

동결자료는 초기 prompt뿐 아니라5개 keyed 기록도 따로 묶는다. 새 중립 양쪽 모두 READ PING→정확한 PING 반환→READY, 각2턴을 실제 확인했다. treatment 중립 첫 준비 실패는 모델 차례·출력 없이 발생했으며 허용된 준비 재시도에서 완료했다. 모든 기록을 남겼고 문제 재시도는 없다. 첫 baseline 공통 문맥 match=false는 새 기준 수립이며 다음 arm에서 실제 일치했다. 새 기준을 원래 계획에 연결한 뒤 r2/r3/r1 attempt1만 실행했다. 실제 최초 task+LF+LF+COMMON, 매 후속 입력의 정확한 기록, 공통 문맥·스킬 미노출·무도구·소스 보존·프로세스 종료·복사 인증 정리를 확인했다.

누적 **39개 시도 문제군·115개 최종 문제 답변·171개 문제 해결 턴**이다. F43은3개 최종 문제 답변과18개 실제 문제 턴을 더한다. 중간 READ 응답15개도 공개 대화에 보존하지만 최종 문제 답변 수에 중복 합산하지 않는다. 중립 실제4턴은 문제 수와 문제 턴에 합산하지 않는다. 모의 답변·정적 확인을 실제 모델 결과로 대신하지 않았다.

익명 채점 자료에는 전체 이용 가능한 C 초기 의뢰·5개 기록, 실제 공개 요청·기록 순서와 최종 답이 있으며 turnID/조건/모델/호스트/작성자 해석/비공개 oracle은 없다. 실제 원본에서 정확한 기록 전달을 확인한 뒤 만들었다. 원래 답은 채점 전에 작성자나 부모가 미리 읽지 않았다. 요청한 gpt-6-sol은 실제 처리 백엔드의 확인이 아니고 추론 수준은 판정 요소가 아니다.

## 보존과 한계

문제 재실행·대체·재채점·H/K·채점 treatment는0회다. 스킬·방법·실행기·설정은 수정하지 않았다. F41 미완료 원본은 미채점·미재실행 상태로 유지한다. 선택된 증명과 기존 전체153개 검사(147통과·환경6건 skip·실패0)는 변경 없어서 재사용했고 새 전체 검사는 하지 않았다. 최종 산출물 두 독립 검토와 로컬 보관은 전체 pool 안정 뒤로 유보돼 있다. 현재 사전 검토·작성자 읽기 확인을 최종 산출물 독립 승인으로 표시하지 않는다.

로컬 작성 한계도 보존했다. freeze helper 파일 편집 뒤 TypeScript LSP 초기화가 실패했지만 파일은 작성됐고 별도 Node 동결은 실제 통과했다. 수집 검사기는 telemetry phase를 처음 final로 가정했다가 실제 final_answer로 고쳤으며 최초 오류는 익명 자료 작성 전에 발생했다. 긴 보고서 작성 heredoc도 절단되어 Node 실행 전에 중단됐고 부분 파일을 보존한 뒤 작은 단계로 작성했다. 모두 실제 문제 재시도·출력 변경·새 채점으로 취급하지 않는다. 설정·인증 내용·숨은 추론·raw native event·프로필은 읽거나 저장하지 않았다. 원문 대화로 받은 채점 JSON의 로컬 해시는 원시 전송 인증을 증명하지 않는다.

자세한 해시·한정 증거는 [evidence.json](evidence.json)에 있다. 확보0/6개로 전체 목표는 미완료다.
