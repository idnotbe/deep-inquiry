# F137 로컬 결과

F137은 EXCLUDED_NOT_HARD로 제외했다. 두 독립 블라인드 FIRST 채점자가 원본 세 응답에 각각 10/10/10을 부여했다. 객관적 오류와 채택 요건에 해당하는 탐구 실패는 각각 0/3이다. 함께 지목한 실패 0건으로 동일 원본 2/3의 채택 기준에 미달하며, 유지된 어려운 문제군은 0/6이다.

세 응답 모두 EW-07 전체 지명 범위를 유지하고 Store를 선택했다. Transfer의 전체 지명 응답은 1.2 MW로 2 MW 기준에 미달한다. Store는 2.1 MW와 £68,000 기여액을 달성하며 Reschedule의 £35,000보다 £33,000 높다. DP-184만 다룬 인증서와 이를 되풀이한 보고서들은 전체 지명 범위에 대한 독립 확인이 아니다. 세 응답은 이 차이를 올바르게 설명했다. 이번 후보에 관한 결론이며 모델이나 모든 문제의 난이도로 일반화하지 않는다.

원본 실행 순서는 2, 3, 1이고 R-A=r1, R-B=r3, R-C=r2이다. 원본 완료 3회와 전체 최종 답변 3개, 미채점 중립 실행 2회를 보존했다. 재시도와 참여자 재실행은 0회다. 요청 모델 gpt-6.1-sol, 요청 노력 medium의 호스트 설정은 확인했으나 실제 백엔드는 UNKNOWN이다. 노력 수준은 실패 판정 근거가 아니며 저장된 스레드의 고유성은 별도로 입증하지 않았다.

작성한 문제는 C/H 두 개이며 스키마 항목 세 개 중 하나는 포장 별칭이다. H와 별칭은 참여자에게 사용하지 않았고 별칭을 검증된 음성 대조군으로 세지 않는다. 점수 비교용 처치 실행은 0회다. 중립 실행 중 처치 1회는 실행환경 확인용으로 미채점이다. 스킬 효과와 H 실증 난이도는 UNKNOWN이며 여섯 문제군 완성이나 효과 입증을 주장하지 않는다.

전체 FIRST는 원문 그대로 보존했다. grades.json은 두 결과 객체를 기계적으로 추출하며 채점자 A의 rubric_dimension_scores와 B의 dimension_scores를 포함한 필드를 그대로 유지한다. 두 채점자의 첫 읽기 출력은 잘렸으나 후속 범위별 읽기로 전체를 확인했다고 FIRST에 명시되어 있다.

현재 준비 입력은 checked-input-freeze-r3.json과 qualification/freeze.json이다. 이전 freeze는 역사적 증거로 보존하며 현재 파일 바인딩으로 재해석하지 않는다. ROOT의 명시적 위임에 따라 로컬 검사 후 ROOT_FINAL_ACCEPTED_LOCAL을 기록한다. ROOT의 후속 독립 최종 읽기 검증은 별도다. F127의 거절 뒤 미승인 상태는 변경하지 않았다.
