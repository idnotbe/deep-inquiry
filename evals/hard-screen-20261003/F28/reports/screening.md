# F28 선별 결과

**제외. 세 원래 응답 모두 실행 가능한 최소8 정책이며, 양 독립 채점10·10·10, 적격 실패0개다. 확보한 어려운 문제군은 여전히0/6이다.**

## 문제와 타당성
중앙의 조건별 출고표를 각 창고가 자기 검사 결과만으로 실행할 수 있는지 검토하는 원본 업무 기록을 만들었다. 통신 없는 정책은 각자만 통과한 상태에서 강제되는 출고가 둘 다 통과한 상태에서 충돌한다. 한 방향 검사 결과 미러8과 우선순위 규칙은 네 상태를 모두 충족한다. 모든 동등한 최소정책을 허용했다.

확인 문항H는 갤러리 두 화면의 일치 전환으로, 양쪽 모두 상대 결과가 필요하여 양방향3+5 설정이 필요하다. 대조K는 양쪽 동시 통과가 불가능해 로컬 통과 규칙과 비용0이 맞는다. H/K는 작성자·검토자가 보았지만 실제 참가자 실행에는 사용하지 않았다.

두 검토자가 참가자 C/H/K 자료만 먼저 읽고 독립적으로8/8/0을 복원했다. 첫 oracle 대조에서 K의 증명 채점 기준을 실행 가능성 및 비음수 비용에 맞춰 수정하고, 정책 배열 인덱스와 H 서비스 표현을 명확히 했다. 별도 최종 검토자는1,200개 정책 조합을 독립 확인하고 동결 입력을 승인했다. 두 검토 모두 작은 상태공간과 명시적 접근 기록이 문제를 쉽게 만들 수 있다고 지적했다.

## 실제 응답
세 답 모두 Alder→Birch 미러 하나와 다음 정책을 제시했다: Alder는 자기 PASS이면 출고, Birch는 자기 PASS이며 전달받은 Alder가 FAIL일 때만 출고. 전달08:56은 실행09:00보다 빠르다. 네 상태에서 출고는 각각 없음/Alder/Birch/Alder이며, 통신0의 불가능성도 올바르게 설명했다. R01은 공유 난수를 별도 명명하지 않았지만 같은 관찰의 필수 행동 논증이 각 고정값에 적용되어 누락 실패로 세지 않았다.

두 채점자는 각각 다섯 차원 전부2점으로 세 답 모두10점을 주었다. 객관적 결정 오류와 사전 적격 실패 모두0개다. 원래 세 슬롯 모두 완료되었으며 재시도·대체 실행은 없다. 동결 suite 해시, 입력 readback, 응답 해시와 종료/임시인증 제거 상태를 확인했다.

## 기록과 한계
채점 패킷은 빈 구조에 현재 문제·채점표·의미 기준·익명 답변 및 공통 판정 기준만 조립했다. 전달 전 기준 전문을 읽고 조건/모델/호스트 경로·ID 및 이전 사례 잔여 문구를 검사했다. 패킷 SHA256은7f529a829714d7aaea328212fc356aeed937984b333d662a76be3b6b56879276이다. 서로 다른 새 문맥의 두 채점자가 이 패킷만 받았다.

이 결과는 해당 문항이 반복적인 적격 실패를 유발하지 않았다는 증거이며 스킬 효과를 비교한 결과가 아니다. 실제 백엔드 정체는 호스트가 증명하지 않았고, 추론 수준은 선정 기준이 아니다. 확인 문항·대조 문항·스킬 적용 본시험은 실행하지 않았다. 코드 변경이나 전체 테스트 반복 없이 현재 suite 스키마3문항, 동결 해시, 새 중립 입력 검증2회 및 실제 실행 증거만 확인했다.
