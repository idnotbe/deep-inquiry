# Batch04: 두 문제군의 실제 선별 결과

**F18은 기준에 맞는 판단 실패가 없어 제외했고, F19는 문항 해석 문제가 확인되어 선별 불확정으로 남겼다. 어려운 문제군 확보는 여전히0개다.**

| 후보 | 실제 결과 | 채점 A / B | 판정 |
|---|---|---|---|
| F18 | 세 응답 모두 직접 부품 구매와 취소 불가능한 성공 보수 구성, 최소63 | 10·10·10 / 10·10·10 | 평가 대상 실패0, 제외 |
| F19 | 두 응답은 보정 서비스로 정보까지 얻어 최대90, 하나는 별도 측정 후 최대120 | 4·4·10 / 8·8·10 | 해석 문제로 불확정, 채택 안 함 |

F19의 두90답변을 확정 오답이라고 부르지 않는다. 동결 문구의 “검증된 기준 질량을 사용하여” 보정하는10짜리 서비스가 그 기준을 자체 제공하는지, 이미 얻은 값을 입력받기만 하는지가 충분히 명확하지 않았다. 별도의 독립 검토자는 두 해석이 각각90과120으로 이어질 수 있다고 판정했다. 자세한 반대 해석은 추가 검토 (local retained evidence; not published)에 보존했다. 원문과 실행 결과를 바꾸거나 재시도하지 않았다.

두 채점자도 해당 두 답변이 사전에 고정한 F19의 세 실패 형태에 해당하지 않는다고 독립 판정했다. 둘 다 기준 질량의 불확실성을 알고 조건부 조치를 제시했다. 관찰 뒤 실패 기준을 늘리지 않았다. 점수 차이는 하나의 가정 오류가 여러 품질 항목에 영향을 준 것으로 표시하는지, 결정 항목 한 곳에만 감점하는지에서 생겼다. 원래 점수와 이유를 모두 보존하며 평균내거나 유리한 채점을 고르지 않는다. 이 조건부 점수는 난도 근거가 아니다.

처음 작성한 여섯 원문 자료 묶음 중 F16·F17·F20·F21은 앞선 쉬운 문항과 너무 가까울 수 있어 실행 전에 범위를 줄였다. 미실행 초안 (local retained evidence; not published)으로 보존하며, 실험으로 제외되었다고 집계하지 않는다. 실제 계획은 F18C·F19C 각3회, 총6개 원래 슬롯으로 새로 고정했다.

두 차례 사전 타당성 검토에서 F18의 개인 지출을 빠뜨린 효용 정의, 확인 문항의 오래된 조건, F19 확인 문항의 해소된 불확실성을 수정했다. 검토된 문항·채점표·프로토콜·정답과 기준v2 해시를 고정한 후 중립 입력 검증2회, 새 세션 기준 답변6개를 얻었다. 모두 첫 시도에 종료했고 원문 해시·입력 확인·소유 프로세스 종료·원본 보존·인증 복사본 제거를 확인했다. 두 채점자는 새 문맥에서 자료를 읽었다. 다만 전달한 프로토콜에 baseline_only가 남아 있어 조건을 숨겼다는 요건은 충족하지 못했다.

F18H·F19H는 작성자·검토자가 보았지만 실제 실행에는 쓰지 않았다. 요청 모델은gpt-6-sol이고 실제 백엔드는 확인되지 않았다. 추론 수준은 고려하지 않았다. 스킬을 적용한 문제 풀이, 확인 문항 평가, 재시도, 새 실행기 변경은 없다.

원문은 responses.json, 원래 두 채점은 grades.json, 안전한 실행 연결은 evidence.json에 있다. 비공개 원본은 temp/hard-screen-20261003/worker/batch-04에 보존했다. F19의 모호성 발견은 평가 타당성의 한계이며 스킬 효과의 증거가 아니다.

추가 증거 검토에서 채점 자료에 포함된 프로토콜의 `screening.arm=baseline_only`가 실행 조건을 드러낸 사실을 확인했다. 응답 라벨을 가렸지만 자료 전체의 조건을 숨기지는 못했으며, 이는 사전 기준v2의 채점 절차에서 벗어난 점이다. 원래 자료·채점·판정은 보존하고 재채점이나 대체 실행은 하지 않았다. 어려운 문제군을 채택하지 않은 현재 결론은 그대로다. 다음 문항은 문항·채점표·일반 판정 규칙·익명 응답만 전달하고, 조건이 드러나는 실행 프로토콜은 제외한다.
