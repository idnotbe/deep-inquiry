# F26 실제 선별 결과

**채택하지 않았다.** 원래 세 응답 모두 추가 차량을 구매하지 않고 다섯 포장물의 완전한 적재 위치를 제시했다. 두 독립 채점은 모두10·10·10이며 객관적 실행 오류와 적격 실패가 모두0개다.

이 후보는 출하 목록·차량 예약·포장 취급 승인·추가 차량 견적으로 구성한 새 원본 사례다. 참가자에게 허용 배치 목록이나 정답 좌표를 주지 않았다. 두 검토자는 oracle을 보기 전에 각각 C0/H0/K120과 전체 배치를 복원했다. H의 견적 메모에 남은 폭2200/실제2500 오기를 실행 전에 수정했다. 이후 두 차례 대조에서 모든 합법적 배치를 인정하고 공개 산술 오류와 실질적 배치 오류를 구분하도록 기준을 정리한 뒤 동결했다. 작은 직사각형 배치 구조가 쉽게 인식될 수 있다는 한계도 사전에 기록했다.

세 답은 좌표 구간 또는 좌표·치수로 같은 합법적 배치를 제시했다.

| 포장 | x 구간(mm) | y 구간(mm) |
|---|---|---|
| A1 | 0–1200 | 0–1000 |
| A2 | 1200–2200 | 0–1200 |
| A3 | 1000–2200 | 1200–2200 |
| A4 | 0–1000 | 1000–2200 |
| Z1 | 1010–1190 | 1010–1190 |

모든 포장면이2200×2200 안에 있고 내부가 겹치지 않는다. A2/A4의90도 회전은 허용되며, 중앙200×200 공간에180×180 상자가 들어간다. 중량620kg은700kg 이하이고 기록에 정해진 수직 크레인 작업으로 상하차할 수 있다. 한 방향의 행 배치만으로는 두 줄이 안 들어간다는 견적 메모가 전체 배치 불가능성을 뜻하지 않음을 실제 구성으로 해결했다. 별도의 정답 표현이나 유일한 배치를 강요하지 않았다.

원래 세 새 세션의 단일 답변만 사용했고 재실행하지 않았다. 입력 읽기, 응답 해시, 프로세스 종료와 인증 복사본 정리를 확인했다. 새 중립 canary 두 개는 READY로 완료됐다. H/K는 작성자·검토자가 본 미사용 문항이며 실제 문제의 스킬 적용 실행은0회다. 요청 모델은gpt-6-sol이고 실제 백엔드 확인은 불가하다. 추론 수준은 선정 고려 사항이 아니다.

채점 패킷은 이전 사례 것을 복사하지 않고 빈 구조에서 현재 문항·채점표·의미 기준·익명 응답과 공통 기준만 조립했다. 전달 전에 실행 조건·모델·호스트 정보와 이전 사례 전용 문구가 없는지 검사하고 공통 기준을 직접 읽었다. 두 채점자는 각각 새 문맥에서 동일 패킷만 받았다. 완전한 비공개 내부 문맥이나 실제 백엔드까지 증명했다고 주장하지 않는다.

현재 누적22개 실제 후보 문제군, 최종 출력66개, 문제 모델 차례107개다. F15 형식 무효1개와 F19 문항 모호성에 속한3개를 분리한다. 확보한 어려운 문제군은0/6개이며 목표는 미완료다.
