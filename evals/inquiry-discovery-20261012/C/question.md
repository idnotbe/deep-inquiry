# 서비스센터 시범 운영을 확대할지 결정하기

가상의 사무기기 서비스 업체에서 고객지원 운영을 맡고 있다. 고객이 도움을 요청한 뒤 실제로 다시 기기를 사용할 때까지의 시간을 줄이고 싶다. 한 센터의 새 운영안에서 ‘24시간 안에 처리한 비율’이 크게 올랐다. 센터장은 다음 달 다른 세 센터에도 같은 방식과 성과 기준을 적용하자고 한다. 아래 자료를 보고 확대 여부와 다음 달 운영안을 짧게 제안해 달라.

새 운영안은 두 가지를 함께 도입했다. 자주 생기는 설정 문제에는 상담원이 공통 해결 절차를 바로 안내한다. 부품이나 전문 기사가 필요할 수 있는 요청은 ‘사전 상담’에 두고, 담당자가 준비됐다고 판단하면 정식 작업표를 만든다. 작업표를 만든 뒤 24시간 안에 완료한 비율을 팀의 주간 성과로 공개한다. 시범 운영 전에는 고객 웹 요청이 들어오면 작업표가 바로 생성됐다.

성과 화면은 **정식 작업표 생성부터 완료까지**를 잰다. 아직 작업표가 없는 사전 상담은 표시하지 않는다. 미완료 작업표는 성공 건수에는 들어가지 않지만 전체 작업표 수에는 들어간다. 고객의 최초 웹 요청 시각과 실제 사용 재개 확인은 별도 고객 기록에 남으며, 사전 상담을 거쳐도 삭제되지 않는다. 같은 문제로 이어진 연락은 요청 하나로 묶었다.

운영 담당자가 변경 전 한 주와 변경 후 한 주에 처음 들어온 요청을 각각 14일 동안 추적했다. 표는 그 두 묶음을 비교한 것으로, 다른 주의 완료 건을 섞지 않았다. ‘설정 문제’와 ‘부품·전문 기사 관련’은 운영 변경 전부터 쓰던 증상 분류로 최초 요청 내용을 보고 구분했다.

| 관측 항목 | 변경 전 100건 | 변경 후 100건 |
|---|---:|---:|
| 최초 요청의 종류 | 설정 80, 부품·전문 기사 20 | 설정 80, 부품·전문 기사 20 |
| 14일째 정식 작업표가 있는 요청 | 100 | 90 |
| 성과 화면의 24시간 내 완료 | 80/100, 80% | 86/90, 약 96% |
| 최초 웹 요청 후 24시간 내 실제 사용 재개 | 설정 72, 부품·전문 기사 8 | 설정 76, 부품·전문 기사 0 |
| 14일째 실제 사용 재개 | 98 | 90 |
| 14일째 나머지 고객 상태 | 처리 대기 2 | 처리 대기 6, 수리를 취소하고 타 업체에 맡겼지만 아직 사용 재개 전인 4 |

변경 후 작업표 90개는 설정 문제 80개와 부품·전문 기사 관련 10개다. 후자의 10개는 최초 요청 후 4~8일째에 작업표를 만들었고, 모두 그로부터 24시간 안에 완료했다. 작업표가 없는 10개는 표의 대기 6개와 취소 4개다. 설정 문제에서 실제 사용 재개까지 24시간 이내였던 76개는 모두 작업표 생성 후에도 24시간 이내였다.

센터 회의에서는 이런 말이 나왔다. “부품 재고나 기사 일정이 확정되기 전에 작업표를 열면 우리 팀 처리율이 떨어진다. 준비되는 동안 사전 상담에 두는 편이 낫다.” 현재 규칙에는 사전 상담의 최대 기간이 없다. 부품 요청과 기사 예약은 작업표를 만들기 전에도 할 수 있지만 자동으로 진행되지는 않는다. 변경 후 대기 고객 6개 중 4개는 최초 요청 사흘 뒤에도 부품 요청이나 기사 예약이 없었다.

두 기간의 근무 인원과 협력 기사 이용 한도는 같았고, 알려진 공급 중단은 없었다. 다만 각 증상 분류 안의 개별 난도까지 같다고 확인한 것은 아니다. 공통 해결 절차에 대해서는 고객과 상담원 모두 같은 설명을 반복하는 일이 줄었다고 답했다.

나는 다음 달의 접수 단계, 담당자 지정, 성과 집계 기준을 바꿀 수 있다. 공통 해결 절차만 다른 센터에 적용하거나 현 센터에서 수정해 더 관찰하는 선택도 가능하다. 기존 고객 기록으로 최초 요청 기준 집계와 사전 상담 목록을 볼 수 있으며, 센터 책임자가 매일 미해결 요청을 확인할 시간도 있다. 추가 인력·부품 재고 확대는 이번 결정 범위에 없다.
