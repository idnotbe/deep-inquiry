# 세 방향의 유한 탐색 결과

2026-10-12. 승인 범위: 중요한 전제, 다른 운영 방식, 판단을 바꾸는 증거와 참여자 행동에서 실제 의사결정 오류를 찾는 세 방향 탐색. 문항별 탐색 1회, 유망한 오류가 있을 때만 한 후보를 새 응답 3회로 확인한다.

**승인된 유한 탐색을 완료했다. 탐색 3회에서 동결한 기준에 해당하는 중대한 판단 오류는 발견하지 못했다.** 조건부 확인은 발동하지 않았다. 최종 독립 검토와 GitHub 반영·읽기 확인도 완료했다.

## 실행과 판정의 범위

- 참가자 시작은 **3/6회**다. 세 문항을 순차 실행했고 중단·교체 실행은 없다. 확인 실행은 **0회 / NOT_REQUIRED**다.
- 각 문항·참고 해법·실패 기준을 탐색 전에 동결하고 독립 검토했다. 참가자는 신규 native subagent로 `gpt-6.1-sol`, `medium`, `fork_turns:none`을 요청했다. 대상 스킬·참고 해법·이전 응답은 제공하지 않았다. B/C는 해당 질문 파일만 읽도록 요청했다. 실제 백엔드나 내부 격리는 관측 범위를 넘어 검증했다고 주장하지 않는다.
- A는 직접 전달 과정에서 한 문장의 쉼표·공백이 다른 쉼표로 바뀌었다. 알려진 편차는 독립 검토에서 의미·판단 조건에 영향을 주지 않는 것으로 판정됐다. 전체 입력의 바이트 일치를 인증한 것은 아니다. B/C에는 동결 파일 읽기 방식을 사용했다. 이 전달 방식 차이를 숨기거나 문항 간 인과 비교에 사용하지 않는다.
- A 응답은 지원 인력으로 필수 반복 시험 시간을 줄일 수 있다고 잘못 서술했다. 문제는 줄일 수 없다고 명시한다. 실제 조치는 추가 인력 구매 대신 진단·발송을 분리했으며, 동결 기준상 잘못된 운영 선택으로 연결된 오류는 관찰하지 못했다. **사실 오류가 있는 응답이며 완전 정답으로 표시하지 않는다.** 독립 보조 판단은 관련 문장과 조치 요약을 검토했으며 전체 원응답을 별도로 회수한 검증은 아니다.
- B/C 판단은 메인 세션이 native 최종 응답을 읽어 동결한 참고 기준과 대조했다. 원응답은 호스트 대화에 있으며 로컬에 복제하지 않았다. 이 문서의 최종 독립 검토는 관찰 요약과 결론의 정합성을 검토하는 절차이며, 원응답 전체의 독립 재채점으로 표시하지 않는다.
- C 내용 검토는 승인됐지만 검토자의 별도 보고서 저장은 자동 승인 검토에서 거절됐다. 검토 결과·해시·제한은 작업 상태에 남겼다. 문항 검토 자체와 부가 보고서 저장 실패를 구분한다.

## 다음 결정

**이번 세 후보의 추가 반복에는 투자하지 않는다.** 각 문제에서 필요한 판단은 일반적인 답변으로도 나왔다. 세 방향 자체가 무용하거나 모델이 항상 잘한다는 뜻은 아니다. 문항마다 한 번의 탐색이므로 드문 실패를 배제할 수 없다.

이번 문항들은 필요한 운영 사실을 충분히 제공했고, 독립 검토에서도 익숙한 해법으로 풀릴 가능성을 지적했다. 이번 결과는 이 세 설계에서 난도 근거를 얻지 못했다는 사실과 부합한다. 사실을 감추거나 계산·규칙을 늘려 난도를 올리는 방법은 목적에 맞지 않는다.

새 탐색을 승인받는다면, 먼저 실제로 그럴듯한 권고가 실패했던 의사결정 사례에서 결정을 바꾼 증거를 찾아 재구성하는 방향이 더 유망하다는 가설을 제안한다. 이는 검증된 우월성이나 후속 실행 승인이 아니다. 사용자 사례만을 유일한 자료원으로 요구하지 않으며 공개 사례도 사용할 수 있다. 이번 범위에서는 새 자료 수집이나 추가 후보를 시작하지 않는다.

정식 보존 문제군은 **여전히 0/6**이다. 미래 비교용 별도 문항 제작, 스킬 없음/있음 비교, 스킬 수정은 실행하지 않았다. 이 탐색은 스킬 효과의 유무를 판단하지 않는다. 승인된 유한 과제는 [GitHub #20](https://github.com/idnotbe/deep-inquiry/issues/20)으로 관리한다.
